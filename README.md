# java-calculator-precourse
문자열 덧셈 계산기 기능 목록

1.[ ] 사용자 입력 기능

사용자로부터 덧셈할 문자열을 입력받는다.

2.[ ] 기본 계산 기능 (빈 문자열, null 처리)

입력값이 빈 문자열이거나 null일 경우 0을 반환한다.

3.[ ] 기본 구분자 처리 기능

쉼표(,) 또는 콜론(:)을 구분자로 문자열을 분리한다.

4.[ ] 숫자 변환 및 합산 기능

분리된 각 문자열을 숫자로 변환하고 합산하여 결과를 반환한다.

5.[ ] 커스텀 구분자 처리 기능

//와 \n 사이의 문자를 커스텀 구분자로 식별하여 문자열을 분리한다.

6.[ ] 예외 처리 기능

입력값에 음수가 포함된 경우 IllegalArgumentException을 발생시킨다.

입력값에 숫자가 아닌 문자가 포함된 경우 IllegalArgumentException을 발생시킨다.

7.[ ] 결과 출력 기능

최종 계산 결과를 출력한다.

8.[ ] 애플리케이션 흐름 제어

전체적인 입/출력 및 계산 흐름을 제어한다.
